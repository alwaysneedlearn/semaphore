Semaphore RDP Helper

未连接

用法： ① 左侧选/建项目环境 → ② 填 Semaphore 地址与跳板 → 保存 → ③ 连接 → 打开网页 → ④ 在 Semaphore 设备列表点「远程桌面」

项目环境

每个「项目环境」一套跳板 + Semaphore 入口；多项目可同时连接，互不影响。先连接再开网页。

当前项目配置

能直接打开 Semaphore 时用这个；打开网页会跳到该地址。

若本机已能直连 Semaphore、只是设备 RDP 要跳板：取消勾选此项，下方「打开网页地址」填直连 URL，仍配置跳板用于远程桌面。

映射含义：ssh -L 本机端口:内网主机:内网端口。然后浏览器打开「打开网页用的地址」。

不映射 UI 时，点「打开网页」会打开这个直连地址；SSH 隧道只用于设备 RDP。

高级：落地机 / 密钥（一般不用填）

未填落地机时，SSH 连最后一跳，端口用该跳板的「端口」。只有单独填写了落地机才用「落地机 SSH 端口」。
